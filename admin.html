    Publier sur GitHub

    Le site lit ses poèmes dans le fichier poems.json du dépôt GitHub. Pour que le bouton Publier fonctionne, l’atelier a besoin d’un jeton d’accès limité à ce dépôt.

    Comment créer le jeton ?
    1. Sur GitHub : Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. Repository access : « Only select repositories » → choisis uniquement le dépôt du site.
    3. Permissions → Contents : « Read and write ». Rien d’autre.
    4. Copie le jeton et colle-le ici. Ne le partage jamais.

    Sauvegarde

    Télécharge tous les poèmes dans un fichier, ou recharge un fichier poems.json.
